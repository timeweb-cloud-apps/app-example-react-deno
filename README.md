# react on deno

Пример react на deno для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `deno` |
| Фреймворк в API | `react` |
| Тип приложения | `frontend` |
| Команда сборки | `deno task build` |
| Директория сборки | `dist` |

## Локальный запуск

```bash
deno install --allow-scripts
deno task build
```
